# 协作项目中的助手成员

员工与助手都是明确加入项目的成员。只有已接受的人和助手可被 @；助手由项目所有者发送邀请并立即接受，加入本身不执行。助手身份及引擎固定，设置只修改模型和思考强度。移除助手停止后续提及，但保留讨论历史及会话；重新邀请同一助手继续使用原有身份及会话。

每个讨论、每个助手分别维护稳定会话键和已处理消息进度。一次消息可 @ 多名助手，各自预留运行、计费并执行；同一助手在该讨论中同时最多执行一次。其他助手运行不会阻塞它。每次上下文覆盖该助手上次成功触发消息之后到当前触发消息为止的全部群聊记录，含员工、其他助手及系统消息；其他助手的 @ 不推进它的进度。失败不丢弃尚未成功处理的讨论。

项目成员设置里的模型及思考强度用于后续执行，运行中的助手先完成当前轮再允许修改。引擎不可替换；模型调整通过原生会话恢复应用配置，不能删除或新建已有会话。已有单助手讨论迁移为一个已加入助手，并保留原会话键和进度。

@ 员工产生持久通知，链接包含项目、讨论和消息 ID。打开通知后加载讨论历史并定位、高亮该消息；离群人员仍受成员权限限制。

新增 collaboration 表：shared_assistant_members、shared_assistant_sessions。shared_ai_runs 增加 assistant_id 和 assistant_name；shared_messages 增加 author_assistant_id。历史迁移保留原始聊天与运行记录。

模型与思考选项以项目所有者运行环境返回的原生模型目录为准，并与其授权交集筛选；不同模型可有不同强度，不固定低/中/高。新邀请采用该模型的推荐强度。实际原生模型与逻辑计费模型分别传递，调整模型不改变触发员工的计费归属。
