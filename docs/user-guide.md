# WorkAgent3 使用指南

适用对象：日常办公用户、项目协作成员和平台管理员。  
核对日期：2026 年 9 月 10 日。本文依据当前 Web 界面实现及项目验收记录整理；可用模型、技能、消息渠道和额度以你的账户实际显示为准。

WorkAgent3 是通过浏览器使用的办公智能体工作空间。你可以把资料放进项目，用对话安排分析、写作和文件处理任务，再预览、下载结果；也可以配置专用助手、安排定时执行，或与同事共享项目。

第一次使用，先完成下面的快速上手；日常操作可以直接按目录查找。

## 1. 第一次使用

### 1.1 登录账户

1. 用浏览器打开管理员提供的 WorkAgent 访问地址。
2. 输入用户名和密码，点击「登录」。账户由管理员创建。
3. 按需勾选「记住我」。当前实现中，勾选后登录有效期为 30 天；未勾选时仅在当前浏览器会话中保留登录，服务端有效期为 12 小时。主动退出或密码变更可能提前结束登录状态。
4. 普通用户进入工作空间；管理员若进入「管理空间」，点击「返回工作空间」即可开始办公。

登录页提供「修改密码」：填写用户名、旧密码和两次新密码。新密码至少 12 个字符，且不能与旧密码相同。修改成功后重新登录。忘记旧密码时请联系管理员重置。

### 1.2 完成第一个任务

以整理会议纪要为例：

1. 点击侧栏「项目」，选择「新建项目」，输入“部门例会”并创建。
2. 在该项目点击「新建会话」，选择一个已启用且可用的助手。
3. 点击输入区的附件按钮，上传会议记录。也可以把文件拖入输入区。
4. 确认资料已上传并出现在输入内容的文件引用中，然后输入：

   > 请根据这份会议记录整理中文纪要，包含讨论结论、待办事项、负责人和截止日期。原文未给出的信息标为“待确认”。先在对话中给出结果。

5. 点击发送箭头，等待结果。如出现「需要授权」，查看操作内容后选择「允许本次」或「拒绝」。
6. 需要形成文件时继续补充：“请将确认后的纪要保存为 Word 文件，并给出下载链接。”文档制作所需技能的启用方法见[第 6 节](#capabilities)。
7. 点击回复中的文件链接，或打开文件面板，预览、下载结果。

同一事项的后续工作继续使用这个项目。若要重新开始一段讨论，在项目内新建会话即可，已有项目文件仍可引用。

### 1.3 接下来该用哪个入口？

日常写作、资料整理和文件处理，可以先从一个助手、一段目标清楚的对话开始。根据工作进展选择下一步：

| 你现在要做什么                     | 怎么操作                                   |
| ---------------------------------- | ------------------------------------------ |
| 修改刚才的结果、补充同一任务的要求 | 继续当前会话，指出具体修改位置和标准       |
| 同一批资料进入新的工作阶段         | 在原项目新建会话，引用上阶段保存的结果文件 |
| 从某次回复尝试另一种方案           | 使用分支，保留原来的讨论路线               |
| 主任务运行时顺便问一个相关问题     | 使用 `/btw` 侧聊                           |
| 让同事一起看资料、讨论结果         | 使用「协作 → 共享项目」                    |
| 把任务拆给多个 AI 成员执行或复核   | 使用「协作 → 智能体团队」                  |
| 按固定时间重复执行                 | 创建定时任务                               |

## 2. 界面入口与基本概念

| 入口                         | 主要用途                                            |
| ---------------------------- | --------------------------------------------------- |
| 新对话／项目中的新建会话     | 选择助手，开始一项工作                              |
| 侧栏项目与对话列表           | 打开历史会话，搜索、置顶、重命名和删除              |
| 项目                         | 创建项目，集中管理文件和相关会话                    |
| 文件图标／项目的「管理文件」 | 上传、预览、下载和整理项目文件                      |
| 定时任务                     | 创建计划，查看下次执行时间和运行记录                |
| 协作 → 共享项目              | 与同事共享资料和对话                                |
| 协作 → 智能体团队            | 配置多个 AI 成员并分派任务                          |
| 设置                         | 管理助手、模型、技能、MCP、市场、消息渠道和系统设置 |
| 通知图标                     | 查看站内通知和公告                                  |
| 聊天模式                     | 打开配置好的独立聊天网页                            |

几个名称的区别：

| 名称     | 含义                                                                   |
| -------- | ---------------------------------------------------------------------- |
| 项目     | 一组相关文件与会话的归属空间。同一项目的不同会话可以使用同一批项目文件 |
| 会话     | 一段持续的讨论历史；项目中的其他会话不会自动成为它的聊天上下文         |
| 助手     | 一套角色与工作方式配置，包括引擎、提示词、技能和 MCP 服务              |
| 引擎     | 实际执行任务的系统，当前包括 Codex、Kimi 和通用引擎 DSH                |
| 模型     | 引擎可调用的具体模型，在模型选择器中选择                               |
| 技能     | 针对某类任务的操作方法与配套资源，例如制作 Excel 或处理 PDF            |
| MCP 服务 | 助手连接外部工具或数据服务的入口，部分服务需要单独授权                 |
| 产物     | 任务生成并可打开或下载的文件，例如报告、表格和演示文稿                 |

“上下文”是助手本次处理任务时能参考的信息，包括会话消息、读取的资料和工具结果。“Token”是模型处理内容的计量单位，不等于字数；用户端直接查看剩余额度百分比即可。“CLI”指命令行程序，平台已接入相应引擎，日常使用仍在网页上完成。

手机端通过导航菜单切换项目和会话；选择会话后菜单会收起。输入区的模型、思考强度和权限可通过「模型与权限设置」展开。

## 3. 对话与任务控制

### 3.1 把任务说明白

简单修改可以直接说清要求；需要多步执行或生成正式文件时，按下面五项组织任务：

| 要素               | 要说明什么                 | 例子                                       |
| ------------------ | -------------------------- | ------------------------------------------ |
| 背景与资料         | 结果给谁看，处理哪些输入   | 给部门负责人查看，只使用本项目的销售明细   |
| 目标与成功标准     | 做到什么才算完成           | 按月份、部门汇总，列出重复订单和缺失值     |
| 约束与操作范围     | 可以修改什么，需要保留什么 | 保留原始表，另存分析结果，不覆盖原文件     |
| 输出与证据         | 格式、长度、来源和检查要求 | Excel 汇总表、趋势图、异常清单及来源说明   |
| 结束条件与缺口处理 | 何时交付，缺资料时如何处理 | 检查汇总与明细一致后交付；缺字段时注明影响 |

可复制这个模板，替换方括号中的内容：

```text
背景与资料：这项工作用于【场景】，读者是【对象】。请使用【指定文件或资料范围】。
目标与成功标准：完成【目标】，必须包含【内容】，并满足【可核对的标准】。
约束与操作范围：可以【允许的操作】；保留【原文件或已有内容】；涉及【需确认事项】时先询问。
输出与证据：保存为【文件格式和名称】，并提供【来源、计算依据或修改清单】。
结束条件与缺口处理：完成【检查项】后交付；缺少资料时说明缺口和影响，不补造信息。
```

使用 `@` 或「引用项目文件」选择资料，比只写“处理那个表格”更清楚。需要特定技能时，在输入框键入 `/`，选择当前助手已加载的技能，继续补充任务要求。

任务范围大时，可以先要求提纲或一小段样稿，确定结构后继续完成。后续修改尽量具体，例如“保留表格和数据，只把第 2 节改为面向非技术读者的说明”，避免反复重做已经确认的内容。

### 3.2 发送、排队和立即追加

任务运行时，输入区同时保留发送箭头与停止方形按钮。

| 操作                     | 效果                                                     |
| ------------------------ | -------------------------------------------------------- |
| 空闲时发送               | 开始新一轮任务                                           |
| 运行时排队发送           | 将消息放入待发送队列，当前任务正常完成后按顺序执行       |
| 运行时立即追加           | 把补充要求交给当前正在执行的任务；具体续接方式由引擎处理 |
| 队列中的「立即追加」按钮 | 将这一条排队消息提交给当前任务；空闲时直接发送           |
| 队列中的移除按钮         | 移除尚未发送的这一条消息                                 |
| 停止按钮                 | 请求停止当前轮任务；已经产生的文件修改不会因此撤销       |

默认发送方式是排队，可在设置中调整「任务运行时的发送方式」。例如，“再生成一份摘要”适合排队；“刚才的金额单位应为万元”适合立即追加。

排队内容保存在服务端，不要求浏览器一直打开。当前任务停止、失败或运行环境重启后，队列会保留，需由你选择继续发送。提交失败时先看错误提示，确认消息是否仍在队列中。

### 3.3 快捷键

| 快捷键或输入                  | 用途                             |
| ----------------------------- | -------------------------------- |
| `Enter`                       | 发送；运行时遵循已设置的发送方式 |
| `Shift + Enter`               | 换行                             |
| `Ctrl + Enter`／`Cmd + Enter` | 运行时临时使用另一种发送方式     |
| `Alt + ↑`／`Alt + ↓`          | 浏览历史输入                     |
| `@`                           | 查找并引用项目文件               |
| `/`                           | 打开命令与已加载技能菜单         |
| `/btw 问题`                   | 发起侧聊                         |

中文输入法确认候选词时不会直接发送消息。

### 3.4 授权、过程与结果

需要确认的操作会显示审批卡，包含工具名称、摘要和可展开的操作详情。你可以「允许本次」「拒绝」或「停止任务」。重新打开会话时，仍待处理的审批会再次显示。

回复中可展示 Markdown 表格、代码、公式和 Mermaid 图表。工具调用记录可以展开，查看输入、输出、完成或失败状态，以及可定位的文件位置。过程信息仅限引擎实际提供的内容。

任务显示完成后，按交付要求检查结果：

- **内容**：是否覆盖要求，事实与引用是否能回到来源核对。
- **数字**：单位、日期、合计和计算口径是否一致；扫描件中的关键数字是否识别正确。
- **文件**：能否打开，工作表、页码、图表和排版是否完整，保存名称是否正确。
- **改动范围**：实际改动了哪些文件，要求保留的原始资料是否仍在。

发现问题时在原会话指出位置、正确依据和期望结果，例如：“汇总表 B8 应与明细表本月记录合计一致，请检查公式后另存修订版。”

### 3.5 编辑、分支与侧聊

- **编辑并重发**：在自己的消息下点击编辑。系统以修改后的输入建立新分支；原会话保留。若原任务仍在运行，先停止后再处理编辑请求。
- **从回复分支**：在助手回复下点击分支，保留到该回复为止的历史，用于尝试另一种方案。
- **侧聊**：发送 `/btw 问题`，在独立区域询问相关问题，不打断主任务。侧聊使用创建时的主会话上下文，后续消息不会自动回写主会话。
- **新侧聊／删除侧聊**：新侧聊重新取得当时的上下文；删除侧聊会删除它的消息，主对话保留。侧聊不单独列入普通对话列表。

**分支和侧聊共享所属项目的文件，不是文件副本或文件回滚。** 部分分支通过可见文字历史恢复上下文，并不复制完整工具过程。

### 3.6 整理历史会话

侧栏支持按对话名称搜索、置顶、重命名和删除。已置顶的会话可拖动调整顺序；置顶与顺序保存在当前浏览器。

点击「多选对话」可选择多个会话，或「全选当前列表」后批量删除。若只有部分删除成功，失败项会保留选中并显示错误。删除会话与删除项目文件是不同操作，清理文件请使用文件面板。

## 4. 项目、文件和产物

### 4.1 创建和整理项目

在「项目」页面点击「新建项目」，填写名称后创建。首页也可以先创建项目、上传资料，再发送任务。项目名称应简明，避免同名及 `\ / : * ? " < > |` 等文件名非法字符。

项目支持搜索、重命名和删除。重命名修改显示名称，不会重新搬移已有文件。删除会将项目从列表移除，并把项目文件移入回收目录；删除前应先处理依赖该项目的任务。目前没有面向用户的回收站恢复界面，需要恢复时联系管理员。不要把删除项目当成即时释放磁盘空间的方法。

需要长期查找资料时，可采用一致的名称，例如项目“2026-09-采购部-供应商评估”，其中的会话分别命名为“01-资料整理”“02-评分汇总”“03-报告复核”。阶段文件可命名为“评估报告-v1.docx”“评估报告-v2.docx”。这些版本名用于区分文件，需要保留旧版时应明确要求另存。

### 4.2 上传与续传

个人项目可从输入区添加附件、粘贴文件、拖入文件，或在文件面板点击上传。上传完成后，检查文件引用，再发送任务。

| 场景                              | 当前限制                                  |
| --------------------------------- | ----------------------------------------- |
| 个人项目文件／会话附件            | 单个最大 5 GiB，界面标为「5 GB」          |
| 「协作 → 共享项目」的共享资料上传 | 单个最大 6 MiB                            |
| 本地技能目录或 ZIP 包导入         | 文件总量最大 48 MiB，界面标为「48 MB」    |
| 消息提醒同时发送产物文件          | 单个不超过 50 MiB，并要求渠道支持文件发送 |
| 浏览器文本编辑                    | 最多 2 MiB 的受支持 UTF-8 文本文件        |

个人项目的大文件上传支持分块、进度显示、暂停、取消和恢复。上传中断或刷新页面后，在文件栏展开「未完成上传」，重新选择**同一个原文件**继续。未完成上传暂存最多保留 7 天；超出暂存期限需重新上传。上传期间仍受账户可用存储空间限制。

### 4.3 浏览与下载文件

打开文件面板，选择项目和目录。可以新建文件、新建文件夹，以及对已有文件下载、重命名、移动或删除。把文件拖到高亮的文件夹即可归类，也可以勾选多个文件后选择「移动到…」，在窗口中选文件夹或新建文件夹，再点「移动到这里」。拖到「根目录」可移回项目顶层。移动保留文件名；同名时可保留两份，不会覆盖已有文件；完成后可点击「撤销移动」。桌面端可调整文件栏宽度、最大化预览；手机端在文件列表与预览之间返回切换。

当前预览包括：

- 常见图片、PDF、文本和代码。
- Markdown、HTML，可切换预览与源码。
- Word `.docx` 文档预览。
- Excel `.xlsx`、PowerPoint `.pptx` 经文档转换服务生成的 PDF 预览。

不支持的格式、过大的文件或转换失败的文档，仍可下载原文件查看。Office 预览不是浏览器内的 Word、Excel、PowerPoint 完整编辑器；需要修改时可让助手处理，或下载后用本地办公软件编辑。

### 4.4 在线编辑文本

受支持的文本文件预览中提供「编辑文件」。可以打开多个文件标签，修改后查看差异，再保存。

如果文件已被助手或其他进程修改，保存时会提示冲突并保留你的草稿。重新读取文件、核对最新内容后再决定如何合并。存在未保存编辑时，移动或重命名会排队，保存或关闭编辑后再进行；删除仍需先处理草稿。同一项目的助手正在工作时，移动会等待本轮任务结束，期间可以取消移动。

编辑草稿可在同一浏览器标签页刷新后恢复，退出登录会清理草稿；需要保留的内容请及时保存。

### 4.5 找到任务产物

任务完成后，先查看最终回复中的文件链接和产物区域；也可在项目文件面板刷新查看。支持定位的文件链接或工具位置可直接打开对应文件，有行号时定位到相应位置。

通过文件管理器移动后，文件预览、下载及产物引用会同步到新位置；助手下一轮工作会自动收到位置变更。新文件引用使用稳定标识，旧路径有歧义时会提示重新选择文件，不会猜测并打开另一份同名文件。文件内容里手写的路径不自动改写。

下载到电脑才是本地副本。上传与生成的文件保存在服务器项目中，助手不会因为你输入了电脑上的文件名，就自动获得该本地文件。

## 5. 助手、模型与权限

### 5.1 选择或创建助手

打开「设置 → 助手」：

1. 内置助手可通过开关启用或关闭。初始配置中 Codex、Kimi 开启，DSH 关闭；账户已保存的开关选择会保留。
2. 创建专用助手时，填写名称，选择引擎，再选择技能、MCP 服务并编写系统提示词。
3. 点击「创建助手」；修改自建助手后点击「保存助手」。

例如创建“周报整理助手”，提示词可写为：

> 你负责整理部门周报。使用中文，按本周完成、风险问题、下周计划组织内容。每条结论注明来源文件；缺失的负责人或日期标为待确认。生成文件时保留原始资料。

技能和 MCP 列表支持按名称搜索和多选。内置助手的角色配置受保护；需要修改角色或能力组合时创建自己的助手。

修改助手配置主要影响之后创建的会话，已有会话保留创建时的助手配置快照。关闭助手会将其移出新对话选择器，已有会话仍可继续。

### 5.2 模型与思考强度

在「设置 → 模型」为各助手设置新对话默认模型、思考强度和权限。可选模型来自当前引擎实际返回的列表；不同模型提供的思考强度选项可能不同。

这些默认值自动保存在**当前浏览器**，不同设备需要分别设置。输入区的临时选择不会修改默认值，也不表示定时任务或消息渠道会自动继承这些浏览器偏好。

已有会话中的模型或思考强度，可在选择器可用时调整；任务运行期间不可更改。暂无模型或无法获取时，先检查连接与账户授权，再重新打开网页。

先分清三个设置的作用：模型决定由哪个模型处理任务，思考强度调整其推理投入，权限决定允许执行哪些操作。提高思考强度不会自动获得文件写入或工具访问权限。

不确定怎样选择时，可用一小段有明确验收标准的任务比较当前可用选项，再查看质量、耗时和额度变化。简单改写、格式调整先用已有默认值；多步计算或交叉核对需要调整时，再比较其他模型或思考档位。Kimi 若提供「开启／关闭」思考选项，按页面选择即可；其他模型可能显示低、中、高等档位。具体模型名称、默认值与价格以当前平台为准。

### 5.3 选择权限

| 权限       | 使用场景                                                 |
| ---------- | -------------------------------------------------------- |
| 只读       | 阅读、分析已有资料，不安排修改文件                       |
| 项目内读写 | 日常办公，允许在项目中生成、编辑文件                     |
| 完全访问   | 需要更广的文件或命令操作范围时使用，须理解具体操作的影响 |

权限由各引擎执行，仍受员工账户和系统访问权限约束。Codex、Kimi 的会话可在空闲时通过「当前会话权限」调整；DSH 已有会话的权限控件不可直接修改，应在新建会话前选择。以页面显示的实际权限和审批提示为准。

## 6. 技能、MCP 服务与市场

### 6.1 启用适合工作的技能

「设置 → 技能」显示已安装技能及其状态，所有技能（含平台受管技能）均可通过「启用／停用」按钮开关。停用的技能不会被自动提供给未选择它的助手，但已加入该技能的助手仍可正常使用；若技能处于不可用状态，需要管理员处理。

所需技能就绪后，在「设置 → 助手」中为专用助手选择它，再使用该助手新建会话。输入框的 `/` 菜单可帮助调用当前助手已加载的技能。

按任务选择直接相关的技能即可。例如制作 Excel 看板时选择表格和看板能力；不要为了“能力齐全”把所有不相关技能都绑定到同一个助手。

当前发布清单包含下列能力，部分默认关闭：

| 任务                             | 对应技能                                                                          |
| -------------------------------- | --------------------------------------------------------------------------------- |
| 阅读、生成、合并、拆分和填写 PDF | `pdf`                                                                             |
| 制作和修改 Word                  | `officecli-docx`                                                                  |
| 制作 Word 表单                   | `officecli-word-form`                                                             |
| 制作、计算和检查 Excel           | `officecli-xlsx`                                                                  |
| 制作 Excel 数据看板              | `officecli-data-dashboard`                                                        |
| 制作财务模型工作簿               | `officecli-financial-model`                                                       |
| 制作和修改 PowerPoint            | `officecli-pptx`                                                                  |
| 建立、导入、查询和维护项目知识库 | `wiki-setup`、`wiki-ingest`、`wiki-query`、`wiki-edit`、`wiki-lint`、`wiki-dream` |
| DWG 图纸分析与工程量核查         | `dwg-quantity-surveyor`，需要对应 MCP 服务                                        |
| 查询获授权的专业数据库           | `professional-database`，需要数据源服务与账户授权                                 |
| 通过消息渠道返回已有文件         | 助手内置的消息发送工具，需要已连接的渠道                                          |

“已安装”“已启用”和“当前助手已加载”是三个不同状态。若助手没有使用预期能力，依次检查这三项；涉及外部服务时还要检查连接与授权。

### 6.2 导入自己的技能

在技能页展开「导入本地技能」，填写技能名称和描述，选择本地目录或 ZIP 包，再点击「导入技能」。包内须包含 `SKILL.md` 及其依赖文件，总量不超过 48 MiB。

导入完成后检查表单下方的结果，启用技能并绑定到助手。技能包提供工作方法和资源，不等同于安装任意可执行客户端插件。

### 6.3 配置 MCP 服务

打开「设置 → MCP 服务」，填写名称，选择连接方式，并按页面填写服务地址或命令。创建后可以启用、停用、测试连接；需要 OAuth 的服务提供「授权」入口。

已有配置可以通过「批量导入 MCP JSON」导入，支持 `command/args/env` 和 `url/headers`。导入结果按服务分别显示，一项失败不会使其他成功项失效。

连接凭据归当前员工账户所有。命令行服务运行在服务器环境中，命令路径必须在服务器可用；需要命令审核的项目应按提示完成复核。配置后点击「测试连接」，完成必要授权，再绑定到助手。

| 状态                   | 处理方式                           |
| ---------------------- | ---------------------------------- |
| `ready`                | 已就绪，可按助手绑定使用           |
| `needs_auth`           | 补充凭据或重新授权                 |
| `needs_review`         | 联系管理员核查命令、路径或导入内容 |
| `failed`／连接测试失败 | 查看该项错误，修正配置后重试       |

### 6.4 从市场获取与发布

在「设置 → 市场」搜索技能、MCP 或助手，查看类型、版本、说明和包含的依赖后点击「获取」。获取助手时会一并处理它需要的技能和 MCP。

需要连接凭据时，填写你自己的凭据。若获取后助手仍停用，先到 MCP 服务页完成授权、连接测试或审核，再启用助手。安装未完成时可按提示重试；下架条目不会使已经获取的资源自动失效。

发布时点击「发布到市场」，选择发布类型和已安装内容，填写市场名称、版本、说明后发布。所选内容及其相关技能、MCP 配置会作为版本共享给其他平台成员；发布前检查提示词和资源中是否包含不应共享的业务内容。连接密钥不随发布者配置共享。作者可以下架自己的条目。

### 6.5 版本更新和项目订阅

市场按同一发布者的能力归组，显示最新版本、当前安装版本及更新说明。点击单项「更新」或「一键更新」才会升级；打开市场、重新登录或发布新版本均不会自动升级。进入「版本记录」可查看每版说明，并主动选用仍在上架的旧版本。任务正在使用相关能力时，普通更新会提示等待任务结束。

在市场的「能力使用范围」中选择「我的能力」、个人项目或协作项目。项目可订阅技能与 MCP，固定使用选择的版本，项目任务开始执行时加载订阅；个人更新和其他项目更新不会改变这个固定版本。协作项目成员可查看订阅，只有负责人能调整；项目菜单「项目能力与版本」可直接打开对应市场。助手仍通过助手选择器或协作项目成员添加。

项目负责人更新订阅后，已经运行的任务按本轮配置完成，后续执行使用新版本。取消订阅会恢复任务原本的能力配置。协作成员在自己的个人任务中使用需要凭据的 MCP 时，仍需配置自己的连接，负责人的密钥不会共享给成员。

管理员可在「管理界面 → 市场能力」针对某项市场技能执行「统一升级」「应急停用」或「应急删除」，填写原因并确认后生效。应急处理会停止使用受影响技能的任务、调整相关引用及项目订阅，保留会话历史和工作文件。离线账户保留待处理记录，完成处理前不能继续执行；管理员可查看结果并重试。被撤销的市场版本不能再次获取或启用。这项处置针对该市场条目的安装版本，独立导入或重新发布的副本仍需单独排查。

## 7. 定时任务

### 7.1 创建一个周期任务

进入侧栏「定时任务」，在新建表单中依次填写：

| 字段           | 如何填写                                         |
| -------------- | ------------------------------------------------ |
| 任务名称       | 便于识别，例如“每周部门周报”                     |
| 执行助手       | 选择要使用的已启用助手                           |
| 所属项目       | 选择资料和结果所在项目                           |
| 绑定技能       | 可选，复用已有执行流程                           |
| 任务内容       | 写明资料范围、处理要求、输出文件和异常处理方式   |
| 执行频率       | 固定间隔、每周或 Cron 表达式                     |
| 时区与执行时间 | 每周和 Cron 任务需核对时区，例如 `Asia/Shanghai` |
| 执行方式       | 每次新建对话，或继续已有对话                     |
| 结果通知       | 每次通知、仅失败时通知或不通知                   |
| 消息提醒       | 可选；任务完成后推送到指定的微信等接收聊天       |
| 启用任务       | 勾选后按计划执行                                 |

例如：选择每周五 17:00，时区 `Asia/Shanghai`，任务内容写“汇总本项目本周新增的工作记录，生成周报，注明缺失信息”。保存后核对卡片上的「下次运行」时间，再用「立即运行」检查一次结果。

使用「继续已有对话」时，只能选择符合条件的同项目、同引擎会话。已有对话适合连续跟踪；每次新建对话适合相互独立的周期报告。

熟悉 Cron 的用户可用五段表达式，例如 `0 9 * * 1-5` 表示在所选时区每周一至周五 09:00 执行。

### 7.2 查看与控制执行

任务卡片提供「编辑任务」「暂停／启用」「立即运行」「运行记录」和「删除」。运行记录展示等待、运行中、成功、失败或已取消，并提供结果、错误和「打开执行对话」入口。待运行或运行中的记录可「取消执行」。

暂停用于停止后续计划触发；如果当前已经开始执行，还需在运行记录中取消本次执行。

任务在服务器执行，关掉网页不等于取消任务。服务器重启、运行容量不足、额度不足、授权失效或必需工具不可用，都可能造成延迟或失败。需要人工审批时，从执行对话处理。

### 7.3 把有效流程保存为技能

未绑定技能的任务执行后，若生成了可复用技能建议，运行记录会显示「预览技能建议」。检查、编辑名称和内容后，点击「保存技能并绑定任务」，后续运行即可使用。也可以忽略建议。不是每次执行都会产生建议。

## 8. 共享项目与智能体团队

### 8.1 与同事共享项目

在左侧「任务、频道、协作」中选择「协作」，新建共享项目；也可以在首页勾选「协作模式」。两个入口使用同一套共享项目。创建后直接进入「项目讨论」，无需配置助手即可讨论。创建人是项目负责人，可以邀请成员、重命名项目、移除成员和转移所有权。

邀请有两种方式：

1. 在项目顶部点「邀请」，搜索姓名或用户名并选择同事，发送后显示成功反馈和待接受状态。对方在协作邀请入口接受或拒绝；接受后进入同一项目。
2. 复制一次性邀请链接。对方打开链接并登录后，点击接受加入项目。有效期默认 72 小时，负责人可以撤销。

选择项目后，在「文件」面板浏览目录、上传、下载和预览共享文件。单个文件最大 5 GB，支持断点续传，同时受负责人共享空间额度限制。同名文件不会覆盖，需更改文件名。

讨论在项目内切换或新建。负责人在「邀请与成员」中发送助手邀请，助手立即接受，可添加多名助手。输入 `@` 只能选择已加入项目的同事或助手；一条消息可提及多个助手，各自执行并回复。提及同事会发送通知，点击通知会跳转并高亮原消息。普通消息、创建项目、接受邀请和上传文件均不会启动助手。助手成员和助手回复显示助手自己的名字，头像按引擎区分（Codex、Kimi 各有不同标识），多名助手同时在群里时便于分辨。

每个讨论中的每名助手复用自己的会话。每次提及它，会读取上次成功提及它之后至当前消息之间的全部群聊内容，包括其他助手的回复；提及其他助手不影响它自己的进度。「更多 → 助手设置」只调整各助手实际支持的模型和思考强度，保留会话，不能把 Kimi 替换为 Codex 等其他助手。运行中的助手结束后才能调整或移除；移出后历史保留，重新邀请同一助手会继续原会话。某个助手忙碌时仍可讨论、提及其他助手；再次提及忙碌助手会保存消息并提示忙碌，不自动排队。每次执行用量由提及该助手的员工承担。

旧团队项目继续通过原项目入口访问，原文件和历史完整保留。本次不提供旧项目转换，不会自动共享或删除；需要员工协作时请新建协作项目。

共享项目和对话可隐藏；成员可以退出，负责人可以移除成员或转移所有权。退出或被移除后不再具有项目访问权限。共享空间占用计入项目拥有者的共享空间额度；个人项目不会自动开放给同事。

### 8.2 让多个 AI 成员分工

团队适合能够独立拆分的工作，例如一名成员整理数据、另一名审查资料，最后汇总；也适合起草完成后交给另一名成员复核。简单改写或步骤严格前后依赖的任务，通常先用一个助手更容易管理。

进入「助手 → AI 团队」：

1. 填写团队名称、负责人名称，选择团队项目和负责人助手，创建团队。
2. 点击「添加成员」，设置成员名称、引擎和助手。例如“资料整理”“数据分析”“报告撰写”。
3. 点击「分派任务」，选择执行成员并填写任务内容。
4. 在「消息与动态」查看任务状态、结果、错误和团队消息；通过「查看执行对话」或「打开成员对话」查看具体过程。
5. 需要停止某项工作时点击「取消任务」。成员可重命名、排序或移除，负责人保留固定角色。

智能体团队中的成员是 AI 助手。多位员工共同讨论与共享资料，应使用「共享项目」。AI 成员会使用团队关联项目的资料，分派涉及同一文件的修改任务时应在任务中明确各自负责的文件或步骤。

分派时写清每个成员的输入、输出文件和完成标准。例如“分析员读取销售明细，输出分析表；复核员等分析表完成后检查合计，输出问题清单”。成员执行同样使用账户模型额度；避免把相同的完整任务重复分派给所有成员。

## 9. 消息渠道与提醒

### 9.1 在消息软件中使用助手

打开「设置 → 消息渠道」，选择渠道并新增账号，按页面完成扫码登录或机器人凭据配置。当前接入包括微信、企业微信、飞书／Lark、钉钉、QQ 和 Telegram；实际可用性取决于外部平台、账号配置及连接状态。

新增或编辑账号时，在「助手与模型」中选择助手、该引擎的模型和思考强度，并核对项目、权限和访问控制。私聊访问默认需要批准，按页面授权提示处理允许访问的用户。

保存后，先在目标聊天发送一条普通消息，确认收到回复。账号中的项目、助手、模型和权限用于新建任务；继续已有任务时保留该任务原有的配置和上下文。访问员工的项目与任务需要使用账号绑定的身份或已批准的用户，群聊中的一次提及不会自动授予访问权限。

从消息软件发给助手的图片、语音、视频和普通文件会先下载完成，再作为当前消息的附件交给助手处理。下载或解密失败的附件会明确提示，不会把尚未接收完整的路径交给助手。网页助手也可以按用户明确要求，使用内置消息工具向已连接聊天发送文字或当前项目内的文件；单个主动发送文件不超过 50 MiB。已有旧会话需要重新加载能力或新建会话后，才会看到新加入的消息工具。

网页与 IM 共用项目和任务。任务列表包含 IM 发起的任务；「频道」按外部聊天查看当前关联的项目和任务。同一任务可以从网页或不同聊天继续，但正在执行时需要等待完成或停止后再提交。任务完成通知推送到聊天时会把该聊天的关联切换到被通知任务，直接回复即可继续；正在选择续接方式或当前任务仍在运行时关联保持不变。

### 9.2 渠道中的常用命令

以下是渠道命令，和网页输入框的 `/` 技能菜单不同。可先发送 `/帮助` 查看当前支持情况。命令支持首字简写，例如 `/新`、`/新对` 都等同于 `/新对话`；简写命中多个命令时会提示补全。

| 命令                                     | 用途                                        |
| ---------------------------------------- | ------------------------------------------- |
| `/新对话`                                | 列出最近 10 个任务和「默认对话」供选择，回复「更多」逐页翻看；附项目序号、名称或 ID 时直接在该项目新建 |
| `/项目`                                  | 查看项目列表                                |
| `/历史`                                  | 列出可继续的任务及所属项目，包括网页任务    |
| `/切换 序号、名称或任务ID`               | 切换当前聊天关联的任务；不附参数时列出候选  |
| `/当前`、`/status`                       | 查看当前关联的项目、任务和任务 ID           |
| `/模型`                                  | 查看模型；附序号或模型 ID 可切换            |
| `/重命名 新名称`                         | 修改当前会话名称                            |
| `/压缩`                                  | 请求压缩当前上下文，能否执行取决于引擎      |
| `/额度`                                  | 查询当前使用额度                            |
| `/继续`                                  | 继续空闲前的会话                            |
| `/取消`                                  | 取消待续接消息或停止当前执行                |
| `/补充 内容`                             | 补充 IM 当前正在执行的普通任务（steer），不另开一轮 |
| `/停止`                                  | 停止 IM 当前关联的普通任务                  |
| `/空闲 分钟`                             | 设置空闲检查时间，`0` 表示不检查            |
| `/策略 询问`、`/策略 继续`、`/策略 新建` | 设置空闲后的续接方式                        |

采用“询问”策略时，空闲后的新消息会暂存，可回复 `1` 继续、`2` 在默认项目新建任务、`3` 取消，也可以使用对应命令。新聊天默认在空闲 30 分钟后询问，已有聊天保留已配置的时长。选择任务时可以直接回复列表编号；只有发起选择的用户可以完成选择。不同聊天的任务关联独立。「设置 → 消息渠道」的账号配置中可以调整该账号的默认空闲检查时间和空闲后策略；聊天内的 `/空闲`、`/策略` 命令只覆盖当前聊天。

### 9.3 任务完成后推送到聊天

协作讨论右上角也有「消息提醒」，沿用相同的接收聊天和产物文件设置，只推送 Agent 成功完成的最终结果及产物，不推送成员发言或系统状态。每位成员独立设置自己的提醒，接收前会检查项目访问权限。

收到协作提醒后，`/历史 [n]` 拉取该讨论最近的 n 条成员和 Agent 消息，默认 2 条（每次 1–100 条）。没有新消息时连续发送会继续向前翻页；出现新消息后从最新处重新拉取。协作不支持通过 IM 发言或控制执行；直接发消息会提示去网页操作，并暂存内容：上一条普通任务未超时时，可选择回复该任务或新建对话；已超时或不存在时，询问是否在默认项目新建对话。收到协作提醒不会刷新上一条普通任务的超时时间。`/补充`、`/停止` 仅作用于当前普通任务，在协作提醒上下文中会提示去网页操作。

在「设置 → 消息提醒」配置：

1. 先连接消息渠道，并在接收聊天中给机器人发送过消息。
2. 点击「刷新聊天列表」，选择接收聊天。
3. 开启「任务完成提醒」，按需勾选「同时发送产物文件」。
4. 点击「保存提醒设置」。

网页对话和定时任务成功完成后，可推送最终回复、产物链接和会话链接。IM 发起的本轮执行在原聊天回复，避免重复提醒；同一任务之后在网页继续时仍按提醒设置推送。通知发出后，接收聊天的关联会切换到被通知任务，在空闲时限内直接回复即可继续该任务；超过空闲时限会先询问继续还是在默认项目新建。

只想为某一个对话开启提醒时，在侧栏找到该对话，点击右侧三个点，再点击「消息提醒」。弹窗会同时显示项目名和对话名，避免同名对话选错；接收聊天默认使用上次选择的渠道，首次使用则选择第一个已连接聊天，通常直接点击确认即可。需要调整时再展开选择；「关闭提醒」只关闭当前对话。三个点中的「管理对话」继续用于重命名或删除。单个对话可以在总开关关闭时独立提醒。

创建或编辑定时任务时，也可勾选「开启消息提醒」并选择「消息提醒到」。这个设置只作用于该定时任务，不要求先开启全局「任务完成提醒」；原来的「结果通知」仍是站内通知策略，两者互不替代。

产物下载链接要求使用对应的 WorkAgent 账户登录；同事仅持有链接，不会自动获得你的私有文件权限。支持文件发送的渠道还可发送不超过 50 MiB 的产物文件。最终回复中链接到的有效项目文件可作为产物，输入附件不会自动全部打包推送。

在「最近推送」查看状态。失败记录可「重试推送」，系统按已有发送记录重试未完成部分。关闭总开关会取消待发送部分，已经发出的消息不会撤回。若链接无法从手机访问，请联系管理员核对对外访问地址；该地址由平台统一配置。

### 9.4 桌面提醒与站内通知

会话中的「开启桌面提醒」需要浏览器授予通知权限，用于提示后台完成和待确认事项；浏览器是否继续运行会影响提醒送达。

通知图标中的站内通知用于公告、维护提示等。它与消息渠道的任务完成推送、浏览器桌面提醒是不同入口，需要分别查看和设置。

## 10. 额度、设置与运行状态

### 10.1 查看剩余额度

设置中的「剩余额度」显示各服务的**每日剩余、每周剩余百分比及进度条**。日额度和周额度同时生效；任何一个耗尽都可能阻止新任务启动。

DSH 与 Codex／ChatGPT 共用同一额度池，Kimi 使用另一额度池。切换到 DSH 不会额外获得一份 Codex 额度。百分比来自服务端同步，任务刚结束时可能需要稍等更新；额度读取失败不等于还有可用额度。

达到限制时，等待对应周期恢复，或联系管理员核实账户额度与重置时间。不要把删除会话理解为退回已经消耗的额度。

### 10.2 存储空间

进入「设置 → 系统与帮助 → 存储空间」，查看个人空间和共享空间用量，点击刷新图标更新。共享空间对应你拥有的共享项目。

启用硬配额后，上传文件和助手生成文件都受限制。空间不足时，下载需要保留的结果，清理明确不再需要的项目文件，或联系管理员调整配额。

### 10.3 显示与输入偏好

设置中可调整字体大小和任务运行时的发送方式；侧栏的主题入口可切换明暗主题。当前工作空间和登录页面使用中文。

不同内容的保存范围如下：

| 内容                                                       | 保存范围                                       |
| ---------------------------------------------------------- | ---------------------------------------------- |
| 项目文件、会话历史、待发送队列                             | 服务端，属于相应账户和项目                     |
| 助手、技能配置、定时任务、渠道和消息提醒配置               | 服务端，按员工账户保存                         |
| 助手默认模型、思考强度、权限、会话置顶与排序、聊天网页地址 | 当前浏览器，不跨设备同步                       |
| 未发送的会话草稿、文本编辑草稿                             | 当前浏览器标签页，支持刷新恢复；退出登录会清理 |

### 10.4 系统状态与任务时限

在「系统与帮助」查看平台、员工服务和任务运行环境等组件状态。遇到持续异常，可先刷新状态，必要时下载诊断报告交给管理员。

「重启运行环境」会中断当前员工正在执行的工作，确认无须保留运行状态后再操作。重启后稍等并刷新状态。

「任务时限（秒）」支持 `0`～`86400`：`0` 表示不限制。时限包含等待审批的时间，达到后停止当前轮任务；保存后从下一轮开始生效，适用于网页、团队、定时和消息渠道任务。

长期未使用的员工运行环境可能被系统回收，下次访问时自动启动。首次进入稍慢时先等待加载；遇到容量限制，稍后重试或联系管理员。

### 10.5 独立聊天模式

侧栏「聊天模式」打开独立聊天网页。在「设置 → 系统与帮助 → 聊天模式」填写管理员提供的「聊天网页地址」，点击「保存聊天地址」。留空使用本站默认入口。

地址只保存在当前浏览器。独立网页可能要求自己的登录状态；入口未配置时打不开，不影响 WorkAgent 项目任务。接入说明见[独立聊天模式](chat-mode.md)。

### 10.6 语音输入

配置并授权语音转写服务后，输入区才会显示可用的麦克风入口。授予麦克风权限，录音后点击停止并转写，转写结果进入草稿，由你检查后发送。

语音需要管理员配置外部服务和账户使用权限。截至本文核对日期，已有验收记录未完成真实语音转写验收；使用前请由管理员确认服务已开通。

### 10.7 减少重复工作和资源消耗

1. 明确引用本次需要的资料，避免让助手反复扫描大量无关文件。
2. 长任务先确认提纲或小样，正式生成时保留已确认内容。
3. 阶段结束后保存结果和待办，再在同一项目新建会话处理下一阶段；新会话需重新引用必要资料。
4. 只对需要复核或可以独立拆分的部分分派团队成员。
5. 定期检查定时任务，不再需要的先暂停，避免计划继续运行。
6. 大文件处理失败时区分模型额度、存储空间和运行资源问题；上传大小符合限制，并不保证所有复杂文件都能一次处理完成。

模型额度、磁盘空间、内存和 CPU 解决的是不同问题。增加磁盘空间不能恢复模型额度；模型额度充足也不代表大型文档转换一定有足够运行资源。反复失败时记录文件规模和错误提示，再请管理员检查。

## 11. 常见办公任务示例

先上传资料、选择对应项目，并确认助手已加载所需技能。以下文字可按实际文件名修改后发送。

### 11.1 分析表格并生成结果文件

> 使用 Excel 技能分析 @销售明细.xlsx。按月份、地区汇总收入，检查重复订单和空值。将原始数据、汇总表、异常明细分别放在不同工作表，添加趋势图。保存为“销售分析.xlsx”，给出下载链接和主要结论。

### 11.2 根据资料制作报告与演示文稿

> 根据本项目中已上传的调研资料，制作一份面向管理层的中文报告和 8 页演示文稿。重点是主要发现、证据、建议和待决策事项。数据注明来源，资料不足处明确标注。分别保存为 Word 和 PowerPoint，完成后提供文件链接。

### 11.3 建立可持续维护的项目知识库

> 使用 wiki-setup 在当前项目建立知识库，再用 wiki-ingest 导入我指定的资料文件夹。保留来源和引用关系，不修改原始资料。完成后说明知识库入口，以及以后如何新增资料和查询。

后续可以用 `wiki-query` 查询，用 `wiki-lint` 检查资料与链接，用 `wiki-dream` 维护。要自动维护时，另建定时任务并明确频率与范围。

### 11.4 核查 DWG 工程量

> 使用 DWG 工程量核查技能检查已上传的建筑图纸。先确认图纸版本、范围、比例与专业，再计算指定楼层的墙体净工程量。列出计算依据、扣减项、图纸冲突和无法确认的项目，输出可核对的表格。

此任务需要已启用对应技能和 DWG MCP 服务。专业数据库查询同样需要服务接入与授权，只能使用账户获准访问的数据源。

### 11.5 批量整理文件

> 检查当前项目的“待整理”文件夹，先列出拟分类和重命名的文件清单，不立即修改。按“日期-事项-文件类型-版本”命名，疑似重复文件单独列出。等我确认清单后再执行，保留原文件副本，并输出原名称、新名称和处理结果。

这个流程适合先核对批量改动范围，再集中执行。原文件副本仍占用存储空间，应先确认有足够空间。

### 11.6 复核已有报告

> 请作为复核人员检查 @经营分析报告.docx，并对照 @经营数据.xlsx。重点检查数字、单位、结论与证据是否一致，以及是否遗漏任务要求。按“问题位置、发现、来源依据、修改建议”输出审查表；无法确认的内容列为待核实。先交付审查表，保留报告原文。

需要第二种思路时，可以让另一名团队成员独立复核，再逐项对照意见。两名助手结论一致也不能代替原始证据。

### 11.7 根据扫描资料提取信息

> 从已上传的扫描 PDF 中提取文件名称、日期、金额和对应页码，整理为 Excel。模糊或无法确定的字符标为“待核对”，不要猜测。完成后列出需人工查看的页码和字段，并检查金额单位是否一致。

扫描件、图片表格的识别结果应回到原图检查关键字段。任务要求查询实时信息时，还应明确要求使用已配置的联网工具，并给出来源和信息日期。

## 13. 管理员操作

管理员登录后使用「管理空间」。这里主要管理账户、额度、存储和员工服务；日常办公通过「返回工作空间」进入。

### 13.1 创建与查找账户

在「账户与额度」点击「创建账户」，填写账户名和至少 12 个字符的初始密码。系统创建独立工作空间，进度显示在账户列表上方。等状态为「账户已就绪」后，再通知成员登录。

账户列表可按账户名或 Windows 用户名搜索，显示状态、额度、最近登录和创建时间。点击「管理」打开该账户的设置。

### 13.2 查看额度和美元消耗

账户「使用额度」显示 Codex／ChatGPT 和 Kimi 的日、周已用美元金额、上限及重置时间。DSH 与 Codex／ChatGPT 共享，不能重复相加。

「消耗统计（美元）」支持选择单个用户或所有用户，设置开始、结束时间后查询区间金额和请求数。时间按管理员浏览器本地时间输入，包含开始时刻、不包含结束时刻。

日、周用量以网关实际扣费为准；区间统计按采集的 token 和价格估算，缺少价格的记录会标明，未计入金额。修改模型美元额度需由负责模型网关的管理员处理，当前页面没有直接编辑美元上限的表单。

### 13.3 管理磁盘空间

进入账户「磁盘空间」，分别设置个人空间和该员工拥有的共享空间上限，单位为 GiB。保存后立即生效，不必重启员工服务。

配额针对数据写入，包含助手生成的文件。调整前先看已用空间，避免把上限设置到无法继续工作的程度。

### 13.4 管理账户与服务

| 操作                | 效果                                                         |
| ------------------- | ------------------------------------------------------------ |
| 停用账户            | 阻止登录并停止正在运行的员工服务                             |
| 启用账户            | 恢复账户访问与员工服务                                       |
| 重置密码            | 设置 WorkAgent 登录密码；不修改受系统管理的 Windows 运行凭据 |
| 重启服务            | 重启该员工运行环境，会中断正在执行的工作                     |
| 修复服务            | 使用现有受管凭据执行修复，不要求重置 Windows 密码            |
| 修改 Windows 用户名 | 调整员工运行账户名称，不等同于修改 WorkAgent 登录名          |
| 资源限制            | 设置内存、CPU、进程数，保存后重启员工服务                    |
| 离职并保留数据      | 停止服务、移除访问权限，保留数据供后续处理                   |
| 永久删除账户        | 对已离职账户永久删除账户及保留数据，须输入页面要求的确认文字 |

服务维护以后台任务执行，页面显示进度，刷新后可继续查看结果。执行离职或永久删除前，应先确认共享项目的负责人和资料交接安排。

### 13.5 数据源与操作记录

账户「数据源」页在接入 Kimi 数据源服务后，可设置是否允许访问、允许的数据源、每日和每月次数；每月上限须不小于每日上限。未接入时页面会明确提示，不代表账户已经具有专业数据库能力。

「操作记录」支持查看、按操作筛选和导出管理记录。系统部署、运行凭据恢复与存储维护另见[运维手册](operations.md)、[员工 Windows 凭据说明](employee-windows-credentials.md)和[共享软件与存储说明](shared-software-storage.md)。
