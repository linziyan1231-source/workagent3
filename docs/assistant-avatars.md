# 助手头像

在「设置 → 助手」中，创建或编辑自定义助手时可以设置头像；已有助手卡片上的「更换头像」也可直接使用，内置助手同样支持。

- 可上传 PNG、JPG、WebP、GIF，文件不超过 5 MB。浏览器自动居中裁成 128 × 128 方形并压缩，GIF 使用静态画面。
- 可直接选择预设头像，或点击「恢复默认」。自定义助手默认显示名字首字，AI管家默认显示星光图案，原始引擎助手保留引擎标识。
- 首页助手选择、助手设置、模型设置、侧边栏会话、对话标题和助手回复使用一致的头像。已有会话优先显示助手当前头像，原有会话快照不改写；助手删除后使用会话保留的头像。
- 上传的头像随当前员工的助手配置保存，不依赖外部图片服务。复制助手时复制当前头像，后续可独立修改。

实现继续使用 `avatar` 字段，允许不超过 65,536 字符的压缩图片或头像标记；兼容原有图片地址。内置助手的员工自定义头像独立保存在 `workagent/builtin-avatars.json`，保留原有开关存储格式。

协作（共享项目）中的助手成员列表和讨论里的助手回复不使用上传头像，而是显示助手自己的名字和按引擎区分的标识头像（Codex、Kimi 等不同颜色与图形），便于区分多名助手。
