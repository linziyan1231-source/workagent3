# WorkAgent3 使用帮助

这本手册写给第一次使用的人：正文只讲"点哪里、说什么、会发生什么"；每节末尾的
**技术说明**写给想多了解一点的人，解释背后的工作机制和限制数字，看不懂也不影响使用。
核对日期：2026 年 9 月 13 日。你实际能用的模型、功能和额度，
以你账户里显示的为准。

## WorkAgent3 能帮你做什么

它就是一个网页，打开就能用，不用在电脑上装任何东西。你可以让它：

- 读你上传的文件，写总结、写报告、做表格、做 PPT；
- 帮你整理一堆乱文件，改名字、分类；
- 到点自动干活，比如每周五下午帮你汇总周报；
- 把做好的网页发给同事，对方点链接就能看；
- 在微信、钉钉等聊天软件里直接跟它说话。

它的工作方式很简单：**你把资料放进一个"项目"，然后用说话的方式告诉它要做什么，
做好了它会给你文件，你检查、下载。**

> **技术说明**：你的文件、对话和配置都保存在服务器上你的专属运行环境里，不保存在
> 浏览器里。所以换电脑、换浏览器登录，东西都还在；长期不用时运行环境会被系统回收，
> 下次访问会自动启动，首次进入稍慢属正常现象。

## 第一次使用：10 分钟完成第一个任务

跟着做一遍，就会了。

1. **登录**：打开公司给你的网址，输入用户名和密码。密码是公司管理员发的，忘了就找
   管理员重置。登录页也能自己改密码（新密码至少 12 位）。
2. **建一个项目**：点左边的「项目」，再点「新建项目」，起个名字，比如"部门例会"。
   项目就像一个文件袋，相关的资料和对话都放在里面。
3. **传一份文件**：在项目里点「新建会话」，选一个助手（先用默认的就行），点输入框
   旁边的附件按钮，把文件传上去。也可以直接把文件拖进输入框。
4. **说出你的要求**：比如——

   > 请根据这份会议记录整理一份中文纪要，写清楚：讨论了什么事、谁负责、什么时候完成。
   > 记录里没说的信息，标上"待确认"，不要自己编。

5. **等它做完**：中途如果弹出"需要授权"的卡片，别慌，那是它要做某个操作前问你同不
   同意，看清楚内容后点「允许本次」或「拒绝」。
6. **拿结果**：想留一份文件，就接着说"请保存为 Word 文件，给我下载链接"。点回复里
   的链接就能下载。

做完这一次，剩下的功能都是在这个基础上多加一点东西，按需往下看就行。

> **技术说明**：勾选「记住我」登录有效期 30 天；不勾选只保留在当前浏览器会话，服务端
> 有效期 12 小时。主动退出或管理员重置密码都会提前结束登录。

## 先认识几个词

| 词 | 大白话解释 |
| -- | ---------- |
| 项目 | 一个文件袋，装一类事情的资料和对话 |
| 会话 | 一次连续的对话。同一件事接着聊，就留在同一个会话里 |
| 助手 | 一个"角色"。默认的助手什么都能干；你也可以建一个"周报助手"这种专门角色 |
| 引擎 | 真正干活的 AI 系统，比如 Codex、Kimi。助手背后是引擎在跑 |
| 模型 | 引擎里的具体型号，就像汽车的排量档位 |
| 思考强度 | 让模型"想多久"。想得久更准但更慢、更费额度 |
| 技能 | 助手的"手艺"，比如做 Excel、做 PDF。助手会哪些手艺，由你给它配 |
| MCP 服务 | 助手连接外部工具的"插头"，比如连数据库、连图纸工具 |
| 额度 | 你的使用配额，像手机流量。用完了要等周期重置，或找管理员 |

## 对话：怎么把事情说清楚

- **说清楚五件事就够了**：给谁看、用哪些资料、要做到什么样、不能动什么、缺资料怎么办。
  说不清也没关系，先让它出个提纲或样稿，你确认后再让它做完整版。想照抄模板的话：

  ```text
  背景与资料：这项工作用于【场景】，读者是【对象】，请使用【指定文件】。
  目标与成功标准：完成【目标】，必须包含【内容】，满足【可核对的标准】。
  约束：可以【允许的操作】；保留【原文件】；涉及【需确认事项】时先问我。
  输出：保存为【格式和文件名】，附上【来源或修改清单】。
  结束条件：完成【检查项】后交付；缺资料时说明缺口，不要编造。
  ```

- **指名道姓地引用文件**：输入 `@` 可以从项目里挑文件，比打字说"那个表格"准确得多。
  注意：只说电脑上的文件名没用，文件要先上传到项目里它才看得到。
- **发送后还能补充**：它在干活时你再发消息，默认会排队，等它做完这轮自动接着做。
  急事就用「立即追加」直接插话。点停止按钮可以让它停下，但已经改好的文件不会变回去。
- **聊岔了可以分支**：在自己的消息上点"编辑"重发，或在某条回复上点"分支"，原来的
  对话都还在，等于开了一条平行路线慢慢试。
- **顺手问个小问题**：发 `/btw 你的问题`，在旁边单独聊，不打断正事。
- **快捷键**：`Enter` 发送，`Shift+Enter` 换行，`Ctrl/Cmd+Enter` 临时换一种发送方式，
  `Alt+↑/↓` 翻历史输入，`@` 引用文件，`/` 打开技能菜单。

> **技术说明**：排队的消息保存在服务器上，关掉浏览器也不会丢；但任务停止、失败或
> 运行环境重启后，队列会停下来等你决定继续。分支和侧聊**共享同一个项目文件**——它们
> 复制的是对话历史，不是文件副本，在分支里改了文件，主对话看到的也是改后的。需要授权
> 的操作会出示审批卡，写明工具名和操作详情；刷新页面不会自动批准，重新打开会话时未
> 处理的审批会再次出现。

## 模型和思考强度怎么选

不确定就用默认，默认值对大多数办公任务都合适。想自己动手调，参考这张表：

| 任务类型 | 建议 | 说明 |
| -------- | ---- | ---- |
| 日常写作、整理、分析 | 默认模型 + 默认思考强度 | 质量和速度最均衡 |
| 简单改写、格式调整 | 较低的思考强度 | 快，省额度 |
| 复杂分析、关键方案、交叉核对 | 更高的思考强度（如 high / xhigh / max） | 想得更深，但更慢、更费额度 |
| 审校、识别图片文字 | Kimi 引擎，需要仔细时开启思考 | 简单任务可关闭思考 |

> **技术说明**：可选模型来自引擎实际返回的列表，不同模型提供的思考档位不同；Kimi 是
> "开启／关闭"式，Codex 系模型是多档位式。你的默认选择只保存在**当前浏览器**，换设备
> 要重新选；任务运行期间不能改模型。额度按模型计费，更高档的思考强度消耗明显更快，
> 调档后留意「剩余额度」的变化。具体型号名称、默认值以你账户显示为准。

## 权限与安全

助手能做哪些操作，由权限档位决定：

| 权限 | 什么时候用 |
| ---- | ---------- |
| 只读 | 只让它看资料、做分析，不让它改任何文件 |
| 项目内读写 | 日常办公用这个，允许在项目里生成和编辑文件 |
| 完全访问 | 确有需要再用，先弄清楚它要做的是什么 |

> **技术说明**：权限由各引擎执行，且不会超出你账户本身的系统权限。Codex、Kimi 的会话
> 在空闲时可以改权限；DSH 会话的权限要在新建前选好。超出权限的操作一定会先弹审批卡，
> 你可以只看详情再决定「允许本次」或「拒绝」。让助手做删除、覆盖、对外发送这类操作前，
> 养成先让它"列出要做哪些改动、确认后再执行"的习惯。

## 项目、文件与产物

- **传文件**：普通文件单个最大 5 GB，大文件断了能续传——上传中断后，在文件栏的
  「未完成上传」里重新选**同一个文件**接着传，7 天内有效。
- **找文件**：先看它最后一条回复里的文件链接；或者打开文件面板（项目的「管理文件」）
  翻一翻。文件可以预览：图片、PDF、Word、Excel、PPT、文本都能直接看。
- **整理文件**：拖到文件夹里就是归类；拖到空白处是移出文件夹。移动不改名、不覆盖，
  弄错了可以点「撤销移动」。
- **改文字**：文本文件可以直接在预览里点「编辑文件」修改，保存前能对比改动。
- **注意**：文件都在服务器上。下载到你的电脑，才算是你本地的副本。删项目会连文件一起
  清走且没有恢复按钮，删之前想清楚。

> **技术说明**：上传按分块进行并显示进度，所以大文件可以暂停、取消、续传；未完成的上传
> 暂存最多 7 天。Excel、PPT 的预览是先由服务器转成 PDF 再显示，不是完整编辑器，需要
> 修改就交给助手或下载后用本地办公软件。共享项目的资料上传单个最大 6 MiB，比个人项目
> 的 5 GB 小得多，大资料请让负责人安排。文件移动后，预览、下载和对话里的引用会跟着走；
> 但文件内容里手写的路径不会自动改。

### 把网页发布出去

项目里做好的网页，可以直接变成任何人能打开的链接，不用懂任何技术：

1. 在对话里说一句：**"把这个网页发布出去"**。
2. 它会问你两件事：**有效期**（默认 5 天，过期自动关闭）和**谁能看**（只有登录用户、
   凭链接的任何人、或凭 8 位访问密码的任何人）。
3. 发布后它把链接给你，转发给需要的人就行。

在「设置 → 网页发布」能看到你发过的所有网页，可以随时停用、重新启用或删除。

> **技术说明**：每次发布会把当时的文件复制成一个固定版本，你之后改项目里的文件不会
> 影响已发布的版本；同名网页再次发布会更新原链接的内容，地址不变。发布的应用有人访问
> 时才启动，空闲约 5 分钟自动休眠，再访问会自动唤醒。网页运行占用的资源计入你自己的
> 配额。访问密码方式有防猜限制（10 分钟内最多试 10 次）；删除网页后链接立即失效。

## 助手、技能和 MCP

- **建自己的助手**：到「设置 → 助手」，起个名字，告诉它"你负责什么、怎么写"，再给
  它配上需要的技能。比如建一个"周报整理助手"。改助手的设置只影响之后新建的会话，
  已经开始的会话不受影响。还能给助手换个头像。
- **公司提供的额外引擎**：如果管理员接入了其他 AI 引擎，会出现在「设置 → 助手 →
  管理员提供的 ACP 引擎」里。按页面提示填上你的连接信息（比如密钥），就能用这些引擎
  建助手。填的内容只有你自己可见，别人看不到。
- **开关技能**：「设置 → MCP与技能」里，每个技能都有「启用／停用」按钮，所有技能
  都能开关。用不上的就关掉，界面更清爽。
- **能用的手艺**：做 PDF、做 Word、做 Excel、做 PPT、做财务模型、建项目知识库、
  分析工程图纸、查专业数据库等。有些需要管理员先开通对应服务。
- **装新技能**：「设置 → 市场」里挑了直接「获取」。自己手头有技能包的，用技能页的
  「导入本地技能」。
- **MCP 服务**：助手要用外部工具时才需要配。在「MCP 服务」区填好信息后点「测试
  连接」；显示 `needs_auth` 就是要你重新授权，显示 `failed` 就看错误提示改了再试。
  你填的密码和密钥只存在你自己的账户里。

> **技术说明**：助手、技能、MCP 是三层关系：助手绑定技能，技能可能依赖某个 MCP 服务。
> "没生效"时按顺序查：技能已安装？已启用？当前助手已加载？依赖的 MCP 连接测试通过？
> 市场里获取的内容可以更新版本，但更新要你手动点，不会自动升级；项目还可以"订阅"某个
> 固定版本，防止中途变化。ACP 引擎的连接信息保存在你的私人凭据区，页面只显示"是否已
> 保存"，不会显示内容本身；它的用量按固定模型额度估算记账。

## 定时任务

让助手到点自动干活，比如每周五 17:00 汇总周报：

1. 点左边「定时任务」，填任务名称、选助手、选项目、写清楚要做什么；
2. 选执行频率（每天、每周或固定间隔），注意核对时区；
3. 保存后看一眼卡片上的「下次运行」时间对不对，点「立即运行」试一次。

任务在服务器上跑，关掉网页也会照常执行。没跑成的话，打开「运行记录」看原因——通常是
额度不够、工具没连好或等你授权，修好原因再手动跑一次。

> **技术说明**：定时任务可以选择"每次新建对话"或"继续已有对话"——前者每次独立，
> 适合周期报告；后者记得住前情，适合连续跟踪。需要审批的任务会在执行对话里等你处理。
> 熟练用户可以用 Cron 表达式（如 `0 9 * * 1-5` 表示工作日早上 9 点）。跑得好流程可以
> 让系统把它沉淀成技能（运行记录里的「预览技能建议」），下次直接复用。

## 和同事一起用

- **共享项目**：「协作 → 共享项目」，建好后邀请同事加入（直接搜名字，或发一个邀请
  链接）。大家看同一批文件，讨论时 `@` 一个助手它就会参与进来。谁 `@` 的助手，用谁的
  额度。
- **AI 团队**：「助手 → AI 团队」可以让几个 AI 分工干活：一个整理数据、一个写报告、
  一个复核。分派任务时写清楚谁负责哪部分、做到什么程度算完。简单的事不必动用团队，
  一个助手更快。

> **技术说明**：共享项目里每个助手都记得自己之前被 `@` 到哪条消息，每次被 `@` 会把
> 之后的聊天都读一遍再回答；它正忙时再 `@` 不会排队，只会记下消息并提示忙碌。共享
> 空间占用算在项目负责人的额度里。退出或被移出项目后，就再也看不到里面的内容。

## 在聊天软件里用

- 「设置 → 消息渠道」可以接入微信、企业微信、飞书、钉钉、QQ、Telegram。按页面提示
  登录后，在聊天里直接发消息就能派活，做好的结果也会回复到聊天里。
- 聊天里发 `/帮助` 能看到所有可用命令，常用的有：`/新对话`、`/项目`、`/历史`、
  `/切换`、`/当前`、`/额度`、`/停止`。
- **完成提醒**：「设置 → 消息提醒」里开启后，任务做完会推消息到你指定的聊天。只想
  给某一个对话开提醒，点那个对话右边的三个点，选「消息提醒」。

> **技术说明**：聊天渠道和网页共用同一批项目和任务，在聊天里开始的活，回到网页上能
> 接着看。你发过去的图片、文件会先从聊天平台下载完整，再交给助手；渠道里发文件给助手
> 单个不超过 50 MiB。完成提醒推送后，在那个聊天里直接回复就能接着这个任务继续聊。

## 额度、存储和设置

- **看额度**：设置里的「剩余额度」有每日和每周两条进度条，任何一条用完都会暂时不能
  开新任务，等周期重置或找管理员。删对话不会退回已用的额度。
- **聊天模式（ChatGPT Pro）**：左边的「聊天模式」打开一个独立聊天网页，地址由管理员
  提供，填在「设置 → 系统与帮助 → 聊天模式」。Pro 每周默认能用 7 次，每周一重置；
  只要发出去了就计一次，失败了也不退，想清楚再发。
- **存储空间**：「设置 → 系统与帮助 → 存储空间」看还剩多少。快满时下载要留的文件，
  删掉确实不要的，或找管理员扩容。
- **哪些设置存在哪**：文件、对话、助手配置都在服务器上，换电脑还在；默认模型、会话
  置顶、聊天地址只存在当前浏览器，换电脑要重设；没发出去的草稿只在当前标签页，退出
  登录就没了。
- **语音输入**：管理员开通后，输入区会出现麦克风，说完自动转成文字，你检查后再发。

> **技术说明**：额度分两个池子——Codex／ChatGPT 和 DSH 共用一个，Kimi 单独一个；
> 切换引擎绕不过额度限制。每日额度和每周额度同时生效。Pro 的计次规则是"发出即计"：
> 失败、取消、中途降级都不退回，手动重发算新的一次；额度每周一北京时间零点重置。
> 「系统与帮助」里还能看各组件状态、下载诊断报告、重启运行环境（会打断正在跑的活），
> 以及给任务设最长时限。

## 智能体适合做什么，不适合做什么

**适合**：有明确资料和目标的事——整理、汇总、改写、翻译、做表做图做文档、按模板批量
处理、对照资料检查、从扫描件里提取信息。

**不适合**：没有资料全凭它编的（它会一本正经地编错）、需要为结果负法律责任或做最终
决策的、以及你自己都没想清楚要什么的事。

**好习惯**：重要数字回到原始文件核对；让它"列出依据和来源"；批量改动前先让它出清单、
你确认后再执行。

## 遇到问题？先自己查这三处

1. **页面顶部的提示**和「设置 → 系统与帮助」里的状态——先看是不是服务在维护。
2. **「剩余额度」**——很多"突然不能用"其实是额度用完了。
3. **「设置 → MCP与技能」的连接测试**——涉及外部工具的问题先看这里。

## 常见问题与恢复顺序

| 你遇到的情况 | 怎么办 |
| ------------ | ------ |
| 登录不上 | 检查密码；忘了或被停用就找管理员 |
| 找不到某个助手 | 「设置 → 助手」里看开关是不是关了 |
| 它说找不到我电脑上的文件 | 文件要先上传到项目，再用 `@` 引用 |
| 找不到刚做好的文件 | 看最后一条回复里的链接，或刷新文件面板 |
| 传到一半断了 | 「未完成上传」里选同一个文件继续 |
| 发了消息没动静 | 可能在排队，或在等你点授权卡片 |
| 定时任务没按时跑 | 看「运行记录」里的原因，常是额度或授权问题 |
| 同事打不开我发的文件链接 | 文件是私有的，要协作就用共享项目 |
| 发布的网页打不开了 | 「设置 → 网页发布」看是不是过期了，重新启用即可 |
| 换了电脑，默认设置没了 | 正常，偏好存在浏览器里，重新选一次就好 |
| 聊天模式打不开 | 先核对聊天网页地址；该服务需要管理员单独接入 |
| 没有语音按钮 | 需要管理员先开通转写服务 |

还是解决不了？在「设置 → 系统与帮助」里提交**问题反馈**：写清楚什么时候、在哪个页面、
做了什么、出现了什么提示，可以附截图（最多 3 张，每张不超过 4 MB）或诊断摘要。提交后
能随时查看处理进度（待处理、处理中、已解决），十分钟内最多提交 10 次。

**注意**：截图和描述里不要带上密码、密钥这类敏感信息。
